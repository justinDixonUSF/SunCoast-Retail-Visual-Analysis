# SunCoast Retail Visual Analysis

## Overview

This project focuses on data visualization using Python and Matplotlib.
It analyzes retail sales and customer data to identify trends, compare
performance, and generate business insights.

The script creates multiple charts that help you understand sales
performance, customer behavior, and marketing effectiveness.

## Technologies Used

-   Python
-   pandas
-   numpy
-   matplotlib

## Features

### Time Series Analysis

-   Quarterly sales trend visualization
-   Sales comparison across different locations over time

### Categorical Analysis

-   Category performance by location
-   Sales composition breakdown by location

### Relationship Analysis

-   Scatter plot of advertising spend versus sales
-   Trendline showing correlation between ad spend and revenue
-   Advertising efficiency over time

### Distribution Analysis

-   Customer age distribution with mean and median
-   Age-based purchasing behavior using boxplots

### Sales Distribution

-   Purchase amount histogram
-   Sales breakdown by price tier using pie chart

### Market Share Analysis

-   Sales share by product category
-   Sales share by location

### Business Dashboard

-   Combined dashboard with:
    -   Sales trend
    -   Ad efficiency
    -   Category market share
    -   Location sales distribution

## How to Run

1.  Install required libraries: pip install pandas numpy matplotlib

2.  Run the script: python your_script_name.py

3.  View the generated charts in the output window.

## Key Insights Generated

-   Sales peak in Q4 due to seasonal demand
-   Miami generates the highest sales
-   Electronics lead in category performance
-   Higher ad spend links to higher sales
-   Mid-range products drive most purchases
-   Customer demographics vary by location

## Notes

-   The script assumes that sales_df and customer_df datasets are
    already created
-   Ensure your data includes required columns such as Sales, Location,
    Category, AdSpend, and Age
